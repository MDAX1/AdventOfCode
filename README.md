# Advent of Code 2020

Mina lösningar till Advent of Code 2020 skrivna i Kotlin.

Projektet innehåller enkla och nybörjarvänliga lösningar med fokus på:

* tydlig kod
* enkel struktur
* grundläggande Kotlin
* problemlösning

Varje dag ligger i ett eget paket och läser input från `src/main/resources`.

## Kör projektet

1. Klona repot
2. Öppna i IntelliJ IDEA
3. Kör valfri `main()`-funktion

## Struktur

* `day01` – Report Repair
* `day02` – Password Philosophy
* `day04` – Passport Processing
* `tomteland` – Rekursion och hierarkier

## Språk

* Kotlin
* Gradle
